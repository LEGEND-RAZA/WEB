Quick answers

How long does my session last?

Your session ID stays available on this server for up to 24 hours after you create it. Deploy within that time.

Is my session private?

Treat it like a password. Anyone with your session ID can use your WhatsApp account, so never share it.

How long does deployment take?

Usually a few minutes. The steps update live while your bot builds.

Can I reuse a session ID?

Each session ID deploys one bot. Get a new one if you need another.
